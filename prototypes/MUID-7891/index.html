MUID-7891 Prototype Rate a parking session
Prototype controls (not part of the product)

Assumptions

The spec leaves these open. These defaults are used so the flow can be clicked through.

  • The only user is a person who has just finished a parking session. No sign-in is needed.
  • A star rating is required. Submitting with no stars shows an inline message and nothing is sent. A comment alone cannot be submitted.
  • The comment is limited to 200 characters. The counter shows what is left and typing stops at the limit.
  • Skip is available on the prompt and on the error screen. After skipping, the user goes to the home screen and the session is marked "Skipped". The prompt does not return, and there is no rating from session history.
  • After the thank-you message, "Done" goes to the home screen. Ratings cannot be edited or submitted twice for the same session.
  • Closing the app mid-prompt keeps the draft. The home screen shows a "Resume rating" banner for that session.
  • If submission fails, the stars and comment are kept and "Try again" is shown. After 3 failed attempts, a message says it is still not working, and Skip stays available. There is no other retry limit.
  • Going offline gives the same error screen with an offline message. Retrying works once the connection is back.
  • After several sessions end back-to-back, only the most recent one gets a prompt. The earlier ones are marked "Not rated".
  • "Completed" means any session that has ended. No exclusions are applied.
  • No analytics events are defined, so none are sent. The sample data and the controls above are for demonstration only.
