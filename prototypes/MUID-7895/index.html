    Assumptions

    • The message appears inline, directly below the button (toast and modal were not chosen).
    • Default: the button stays visible with its label unchanged, and repeated clicks keep a single message (no duplicates). The controls above let you try the alternatives.
    • The message is announced to screen readers through a polite live region.
    • Default: a page reload resets to the initial state; the QA toggle shows the alternative. State is client-side only.
    • Reset to initial state is a QA convenience, not a product feature.
    • If the handler fails, a visible error is shown; analytics failure never blocks the message.
    • Analytics are simulated: all three events are logged on this page, and no network requests are made. English only.
    • Browser support was not specified; the page uses standard features and a native button.
