Hello World Button

Activate the button with mouse, touch, Enter or Space.

Clicks: 0Click → message: –

Analytics events (simulated, in-page only)

    Assumptions

    • Single page, one button, one message; English only; no sign-in or backend.
    • Message is shown inline below the button, so no dismiss step is needed.
    • The button stays visible with the same label after the message appears.
    • Repeated clicks keep one message (no duplicates); the message is not toggled or repeated.
    • The message lives in client-side state only; a reload returns to the initial state.
    • The message is announced to screen readers via a polite live region.
    • All three analytics events from the plan are simulated; hello_world_button_clicked fires on every activation, regardless of input method.
    • "Reset page state" is a prototype-only helper for repeating the test; it is not part of the product.
    • Browser support is not specified; the prototype uses a native <button> for broad support.
